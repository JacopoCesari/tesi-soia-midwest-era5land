# Thesis data

- `target/`: complete yield observations for 135 counties over 1951–2025.
- `auxiliary/`: selected county metadata, acreage, weights and provenance.
- `processed/model_datasets/`: future cutoff-specific model inputs.

All original sources, including 1950 yield, remain in `../../work/data/external/`.
Raw downloads and intermediate weather products remain in `../../work/data/`.
No internal source files or preflight fixtures are included in this clean data area.
