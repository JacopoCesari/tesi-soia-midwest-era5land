\chapter{Empirical Results}
\label{chap:empirical_results}

Building on the econometric specifications and validation protocols formalized in Chapter~\ref{chap:methodology}, this chapter presents the out-of-sample empirical findings of the multi-horizon forecasting framework. Evaluations execute strictly on the expanding test partition spanning harvest years 2011--2025 ($N_{\text{test}} = 15$ campaigns, $M_{\text{test}} = 2{,}025$ county-year evaluations per lead time), with model hyperparameters fixed on the 1985--1995 validation partition across all twelve forecast horizons ($H = 12 \dots 1$).

{
Section~\ref{sec:res_horizon_progression} defines the $H=12$ trend reference and compares fitted forecasts at $H=11,\dots,1$. Subsequent diagnostics, tail-risk assessments, and feature attributions focus on $H=5,\dots,1$, when scores are consistently positive across the model families. The small positive values at $H=6$ are retained in the full comparison.
}

\section{Model Benchmark Across Forecast Horizons}
\label{sec:res_horizon_progression}

{ At $H=12$, forecasts predict a zero anomaly by construction. The reference error is the root mean square of test-period anomalies:}
\begin{equation}
    \text{RMSE}_{\text{naive}} = \sqrt{\frac{1}{M_{\text{test}}} \sum_{Y=2011}^{2025} \sum_{c=1}^C \epsilon_{c,Y}^2} = 6.12\text{ bu/ac}, \quad R^2_{\text{OOS}}(H=12) = 0.00
    \label{eq:rmse_naive_reference}
\end{equation}
{
This baseline defines the trend-relative error reference. Table~\ref{tab:horizon_performance} compares weather-only and integrated specifications, the latter including lagged anomaly $\epsilon_{t-1}$, across the monthly horizons. At $H=1$, all reported forecasts implement harvest closure $H^*(s)$: September for Minnesota and October for the other states. The weather-only LSTM uses PReLU; the integrated LSTM uses a linear head.
}

\input{tables/tab_horizon_performance}

The empirical performance matrix in Table~\ref{tab:horizon_performance} reveals four distinct agrometeorological dynamics across the production cycle:

\paragraph{Pre-Sowing Dormancy Noise Regime ($H = 11 \dots 7$, Dec--Apr).}
{
Before May, weather-only models do not improve on the trend benchmark. These origins precede the main planting period described by \citet{Hoffman2020}. Integrated ElasticNet remains near the baseline, while flexible estimators show larger negative scores. This pattern is consistent with estimation variance under weak signals; it does not establish that all antecedent weather mechanisms are absent.
}

\paragraph{Sowing and Emergence Inflection ($H = 6$, May 31).}
At late spring planting, initial predictive skill begins to emerge. Ingesting seedbed moisture and early thermal pacing ($P - ET_0$, $GDD$), candidate models cross into positive territory: pure meteorological XGBoost reaches $R^2_{\text{OOS}} = +0.01$ (rising to $+0.05$ with prior-year carryover). This marks the operational inflection point where environmental observations first surpass the secular trend benchmark.

\paragraph{In-Season Skill Accumulation ($H = 5 \dots 1$, Jun--Oct).}
{ Predictive accuracy increases as reproductive weather accumulates. Table~\ref{tab:horizon_performance} shows gains during flowering and pod filling, with smaller changes around maturity. The progression is evaluated separately for each information set.}

\paragraph{Marginal Value of Lagged Yield Memory ($\epsilon_{t-1}$).}
{ The weather-only benchmark is followed by a lagged-yield comparison. For tabular models, the added predictor improves harvest scores within each model family. Holding the linear LSTM head fixed, harvest $R^2_{\mathrm{OOS}}$ rises from $0.287$ without lagged yield to $0.336$ with it. The PReLU weather-only score is reported separately, since changing the head also changes the model. Subsequent stress tests retain integrated specifications. These comparisons establish predictive contribution without identifying a specific biological carryover mechanism.}

\subsection{Comparative Model Performance}
\label{sec:res_champion_selection}

{
We examine the active horizons $H=5,\dots,1$ using the configurations selected during validation (Chapter~\ref{chap:methodology}). Table~\ref{tab:horizon_performance} provides the numerical comparison.

Integrated ElasticNet has the highest individual county-level score from June through September. The integrated LSTM leads the individual ranking at harvest closure. Tree ensembles show no consistent improvement over regularized linear regression on monthly inputs. This result supports retaining parsimonious shrinkage in weather-panel comparisons \citep{James2023}.

The integrated LSTM gains skill as summer weather accumulates, reaching its highest score at harvest closure. Its 10-day inputs retain within-month timing, an aspect examined by \citet{Yinetal2026}. The primary benchmark compares feasible forecasting specifications: monthly ElasticNet controls the number of tabular coefficients, while the recurrent network shares parameters across sequence steps. This comparison evaluates the complete solutions. The temporal resolution is fixed before the final test evaluation.

}

\subsection{Macro-Regional Portfolio Forecasts across 15 Test Campaigns}

Regional averages summarize whether forecasts capture shared seasonal departures across the study counties. Table~\ref{tab:yearly_macro_yields} reports predicted and realized mean anomalies at harvest closure $H^*(s)$ for the 15 test campaigns, ordered by realized anomaly. }

\input{tables/tab_yearly_macro_yields}

{
{ Table~\ref{tab:yearly_macro_yields} shows that integrated forecasts recover substantial regional departures from trend. In 2012, the realized mean anomaly was $-4.07\text{ bu/ac}$. ElasticNet and the ensemble predicted $-3.81$ and $-4.28\text{ bu/ac}$, respectively. Small regional errors can coexist with larger local errors, examined below.}

{ Calibration varies across seasons. Tree forecasts remain compressed in the 2016 and 2021 bumper campaigns, consistent with the limited extrapolation of terminal-leaf predictions. ElasticNet projects larger positive departures in these cases, while also underestimating the observed anomalies.}

{ Across test years, the ensemble reduces regional RMSE from $3.84$ to $2.22\text{ bu/ac}$, a reduction of about $42\%$. LSTM has the lowest regional RMSE point estimate, at $2.185$ bu/ac against $2.221$ for the ensemble. The ensemble retains the lowest pooled county-level error. Correlations with regional anomalies are $0.888$ for the ensemble and $0.928$ for LSTM. After trend reconstruction, correlations with regional yield levels are $0.947$ and $0.960$, respectively. These pairs refer to different target spaces and must remain separately labelled.}

All models retain negative regional bias, especially in high-yield seasons. The positive mean observed anomaly is consistent with under-projection by the expanding linear trend. Unobserved management and cultivar changes may also contribute, but these data do not identify their separate effects. ElasticNet has the smallest mean bias among the evaluated models. The structural stability of the trend therefore remains relevant to the interpretation of recent forecast errors.
}

Statistical validity requires verifying that model forecast residuals do not exhibit persistent temporal autocorrelation or uncontrolled spatial clustering. We evaluate serial correlation via county-level temporal $\text{AR}(1)$ coefficients and spatial clustering via cross-sectional Moran's $I$ across the 135 study counties using inverse-distance spatial weights:
\begin{enumerate}
{     \item \textbf{Temporal serial persistence.} At $H^*(s)$, mean county AR(1) coefficients are $-0.087$ for ElasticNet (+Lag), $-0.080$ for XGBoost (+Lag), and $-0.034$ for LSTM (+Lag). Residual spatial clustering remains after weather and lagged yield are included. Resampling complete years preserves the within-year cross-county dependence \citep{Sweetetal2023}.}
\end{enumerate}

\section{Feature Attribution and Agrometeorological Drivers}
\label{sec:res_feature_attribution}

\subsection{Feature Attribution Across Architectures}
\label{sec:res_shap_attribution}

We evaluate agrometeorological sensitivities across model paradigms using Grouped Permutation Feature Importance (GPFI) across 19 predictor groups: 17 weather indicators, lagged yield, and jointly permuted spatial coordinates on the 2011--2025 out-of-sample test panel \citep{Sweetetal2023}. For each physical indicator $j$, all constituent monthly features across the full campaign ($m \in \{\text{Nov}, \dots, \text{Oct}\}$) are permuted jointly across test instances ($\pi_j$). This disrupts the biophysical link with yield anomalies while preserving each within-campaign monthly profile. Predictive degradation is quantified by out-of-sample $R^2$ contraction:
\begin{equation}
    \Delta R^2_{\text{OOS}}(j) = \max\left(0, R^2_{\text{OOS}}(\text{base}) - R^2_{\text{OOS}}(\pi_j)\right)
    \label{eq:pfi_metric}
\end{equation}
evaluated over $N = 5$ permutation repetitions against the standardized out-of-sample denominator $SS_{\text{tot}} = \sum (y_i - \bar{y}_{\text{test}})^2$. 

Because baseline predictive capacity differs across candidate architectures, absolute variance losses are normalized into a Relative Information Share (\%):
\begin{equation}
    s_j = \frac{\Delta R^2_{\text{OOS}}(j)}{\sum_{k=1}^{19} \Delta R^2_{\text{OOS}}(k)} \times 100\%
    \label{eq:pfi_share}
\end{equation}
{ Attribution uses diagnostic tabular fits trained through 2010, with separate September and October input sets for state-specific harvest closure. The LSTM panel uses a surrogate tree fitted to the corresponding sequence forecasts after translating them to the same fixed-2010 trend space. These descriptive fits summarize predictive dependence and are separate from the expanding-window accuracy comparison.}

Figure~\ref{fig:feature_attribution_benchmark} reports the Relative Information Share across all 19 predictor groups for selected integrated specifications at harvest closure horizon $H^*(s)$ (October 31; September 30 for Minnesota), grouped by physical domain.

\subsection{Anomaly Space versus Raw Yield Performance}
\label{sec:res_raw_vs_anomaly}

{
We reconstruct physical yield forecasts by adding the training-only trend to the predicted anomaly, following Equation~\eqref{eq:yield_reconstruction}:
}
\begin{equation}
    \hat{y}_{c,Y}^{(H)} = \hat{\tau}_{c,Y} + \hat{\epsilon}_{c,Y}^{(H)}
    \label{eq:level_projection}
\end{equation}
{
As established in Section~\ref{sec:meth_loss_metrics}, RMSE and MAE are unchanged by reconstruction. The two $R^2$ measures use different denominators: trend-relative anomaly error and centred raw-yield variation. Table~\ref{tab:raw_vs_anomaly_performance} reports both at harvest closure across the $2{,}025$ test observations. Their values answer different questions and should be compared within the same target definition.
}

\input{tables/tab_raw_vs_anomaly_performance}

{
{ The trend benchmark explains $47.4\%$ of raw-yield variation without weather inputs. Reconstruction raises the score to $65.1\%$ for LSTM (+Lag) and $66.2\%$ for the ensemble. Their trend-relative anomaly scores are $0.336$ and $0.358$. Comparisons with raw-yield studies such as \citet{ChenZhang2026} must account for this distinction, the predictor set, and the evaluation design.}
}
